# Jihyeok Kim

KAIST undergraduate (Business and Technology Management, Computer Science double major). I build working AI systems and then study why they fail.

**Research interests.** How an agent should decide where to spend computation, and what representation of the world it should carry so a language model can act on it quickly and correctly: adaptive inference-time compute and step-level verification for LLM agents, and fast, accurate spatial memory for household robots.

## Main projects

| Project | What it is | Year |

| [agibot-x2-agent](https://github.com/kjh0209/agibot-x2-agent) | Language-driven home agent for the AgiBot X2 humanoid. Builds its own occupancy map with simulated LiDAR, learns verified room and object labels with a VLM, and acts through a tool-calling LLM. MuJoCo + ROS 2. | 2026 |
| [cupidcode](https://github.com/kjh0209/cupidcode) | CUPID, a model routing engine for coding agents: picks the model with the best chance of success for each step, verifies, escalates. Paired test vs Opus: 54% lower cost on 16 tasks. I am the founder and CEO. | 2026 |
